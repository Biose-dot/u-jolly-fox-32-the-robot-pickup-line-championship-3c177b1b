Entry for the [make.fun](https://make.fun) bounty
[The Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

A robot that rehearsed love 4,000 times and still blanks on the night — the charm is in the failure, and the punch lands on the simulation number.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> I ran 4,000 simulations of us meeting. In every one I froze, overheated, and forgot my opening line — so hi, I'm the robot from simulation 3,997, and you're even better in person.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
